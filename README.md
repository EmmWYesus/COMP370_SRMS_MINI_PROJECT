# COMP370_SRMS_MINI_PROJECT Mini project 1&2 
This project is a Java-based Server Redundancy Management System. It simulates a primary–backup server model using object-oriented programming. In the system, the Primary Server is responsible for processing client requests during normal operation. If the primary fails, the Backup Server takes over to maintain availability. A Monitor checks the server status through heartbeat signals, and a Client sends requests and automatically switches to the correct active server during failover. Running the project prints heartbeat checks, failover transitions, and request handling steps to the console.
# Server Redundancy Management System
In Mini Project 2 (MP2), the original implementation from MP1 was refactored using design patterns to improve structure and maintainability. The Observer pattern was used so that the Monitor receives automatic notifications from servers when their status changes. The Singleton pattern was applied to the Monitor to ensure that only one monitoring instance exists in the system. The Abstraction–Occurrence pattern was used to move common server attributes into an abstract ServerType class, reducing duplication and improving extensibility. These changes decreased coupling and improved cohesion between classes, making it easier to add new server types or extend system behavior without large modifications.
All files are located inside the src folder. To run the program, compile all Java files and execute MainTest.java, which contains the main method used for testing. When executed, the program demonstrates heartbeat monitoring, status changes, and server failover.
